# Prodamus Predictive 2

Production-сборка Windows-клиента Prodamus с одним видимым потоком подсказок. В настройках можно
выбрать предиктивную схему с двумя Gemini Live-сессиями либо совместимую исходную схему с одним ключом.

## Как работает V2

1. В режиме двух ключей скрытая сессия-прогнозист после законченной фразы менеджера строит три различных сценария следующего хода клиента.
   Каждый сценарий содержит признаки, заметные по первым словам, и подготовленную реакцию менеджера.
2. Прогнозы не отображаются. Клиентское приложение передаёт последний прогноз второй сессии как
   служебный контекст непосредственно по Gemini Live WebSocket.
3. Рекомендатель получает первые примерно 0,6 секунды реплики клиента, выбирает подходящий сценарий
   и сразу показывает одну готовую к произнесению подсказку.
4. Продолжение длинной реплики отправляется без потери аудио через настраиваемые интервалы 1–5 секунд.
   Все фрагменты имеют один `utterance_id`: в карточке существует одна активная гипотеза, которая уточняется
   на месте только при существенном изменении смысла и не размножается на отдельные сообщения.
5. Реальный конец реплики определяется по настраиваемой паузе. После него в ту же карточку обычным шрифтом
   добавляется одна проверенная итоговая рекомендация. Детектор всегда сохраняет реальный аудиохвост для финального
   turn; при редком повторе отправляется валидное непустое аудио, а незаконченный поток не фиксируется как готовая фраза.
6. Лента автоматически прокручивается к последней динамически дописываемой строке.

Backend не проксирует разговор. Он только авторизует приложение и выдаёт constrained ephemeral token.
Для двухсессионного режима используется `POST /api/client/predictive-v2-live-sessions`; односессионный режим
использует исходный `POST /api/client/live-sessions`. Старые клиенты и endpoints не изменены.

## Требования

- Windows 10/11 x64;
- один включённый Gemini credential для совместимого режима либо два разных свободных credential для прогноза;
- доступ к `https://prodamus.abs7.ru` и Gemini Live;
- пользователь с назначенной ролью продаж.

## Разработка

Требуется JDK 21.

```powershell
.\mvnw.cmd test
.\mvnw.cmd spring-boot:run
```

Версия клиента задаётся в `src/main/resources/application.properties`:

```properties
prodamus.client.version=2.0.0
```

## Windows package

```powershell
$env:JAVA_HOME = 'C:\path\to\jdk-21'
.\package-windows.ps1
```

Без WiX скрипт создаёт portable app-image:

```text
dist\Prodamus Predictive 2\Prodamus Predictive 2.exe
```

Нельзя переносить только маленький `.exe`: для запуска нужна вся папка app-image с каталогом `runtime`.
