# Prodamus Predictive 2

Отдельная экспериментальная Windows-сборка Prodamus с двумя Gemini Live-сессиями и одним видимым
потоком подсказок. Она не заменяет ветки `client` и `predictive-client`.

## Как работает V2

1. Скрытая сессия-прогнозист постоянно строит три различных сценария следующего хода клиента.
   Каждый сценарий содержит признаки, заметные по первым словам, и подготовленную реакцию менеджера.
2. Прогнозы не отображаются. Клиентское приложение передаёт последний прогноз второй сессии как
   служебный контекст непосредственно по Gemini Live WebSocket.
3. Рекомендатель получает первые примерно 0,9 секунды реплики клиента, выбирает подходящий сценарий
   и сразу показывает одну готовую к произнесению подсказку.
4. Продолжение длинной реплики отправляется без потери аудио через настраиваемые интервалы 1–5 секунд.
   Каждая ранняя гипотеза полностью дописывается курсивом и остаётся в карточке; следующая гипотеза
   добавляется ниже и не заменяет предыдущую.
5. После окончания реплики в ту же карточку обычным шрифтом добавляется итоговая рекомендация.
   Генерации выполняются последовательно, поэтому следующая не обрывает уже начатую фразу.
6. Лента автоматически прокручивается к последней динамически дописываемой строке.

Backend не проксирует разговор. Он только авторизует приложение и атомарно выдаёт два ephemeral token
от двух разных свободных Gemini credential. Для V2 используется отдельный совместимый endpoint
`POST /api/client/predictive-v2-live-sessions`. Старые endpoints не изменены.

## Требования

- Windows 10/11 x64;
- два разных включённых Gemini credential со свободной ёмкостью в back-office;
- доступ к `https://prodamus.abs7.ru` и Gemini Live;
- пользователь с назначенной ролью продаж.

## Разработка

Требуется JDK 21.

```powershell
.\mvnw.cmd test
.\mvnw.cmd spring-boot:run
```

Версия клиента задаётся в `src/main/resources/application.properties`:

```properties
prodamus.client.version=1.5.1-predictive.2
```

## Windows package

```powershell
$env:JAVA_HOME = 'C:\path\to\jdk-21'
.\package-windows.ps1
```

Без WiX скрипт создаёт portable app-image:

```text
dist\Prodamus Predictive 2\Prodamus Predictive 2.exe
```

Нельзя переносить только маленький `.exe`: для запуска нужна вся папка app-image с каталогом `runtime`.
